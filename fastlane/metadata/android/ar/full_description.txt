WebToApp ورشة على الجهاز لتحويل المواقع ومشاريع الويب المحلية إلى تطبيقات أندرويد. يعمل على هاتفك دون حاسوب ودون خادم بناء عن بُعد.

يمكنك تغليف رابط، أو حزم ملفات HTML أو الواجهة الأمامية، أو إنشاء معرض أو مشغّل وسائط، أو تشغيل خادم Node.js أو PHP أو Python أو Go أو WordPress داخل التطبيق المُنشأ. محرك النظام WebView هو الافتراضي؛ يمكن تنزيل GeckoView (فايرفوكس) لاحقاً.

هذا الإصدار من F-Droid لا يتضمن Firebase Cloud Messaging ولا تسجيل الدخول عبر Google ولا AdMob. تبقى الإشعارات عبر تعويض Web Notification والاستعلام عبر HTTP وWebSocket. تنزيلات المحركات وبيئات التشغيل اختيارية وصريحة.
