WebToApp은 웹사이트와 로컬 웹 프로젝트를 Android 앱으로 만드는 기기 위 작업실입니다. PC와 원격 빌드 서버가 필요 없습니다.

URL을 감싸거나 HTML/프론트엔드를 묶거나 갤러리·미디어 플레이어를 만들거나, 생성된 앱 안에서 Node.js, PHP, Python, Go, WordPress를 돌릴 수 있습니다. 기본 엔진은 시스템 WebView이며 GeckoView(Firefox)는 나중에 받을 수 있습니다.

이 F-Droid 빌드에는 Firebase Cloud Messaging, Google 로그인, AdMob이 없습니다. 푸시는 Web Notification polyfill, HTTP 폴링, WebSocket으로 동작합니다. 엔진과 런타임 다운로드는 명시적으로 선택할 때만 이뤄집니다.
