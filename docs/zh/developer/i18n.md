# 国际化

**宿主**构建器界面本地化为 10 种语言。(这与按应用配置、翻译生成应用*内容*的翻译叠加层相互独立。)

## 支持的语言

中文、英文、阿拉伯文(完整 RTL)、葡萄牙文、西班牙文、法文、德文、俄文、日文、韩文。

## 字符串在哪里

宿主 UI 字符串位于 `app/src/main/java/com/webtoapp/core/i18n/Strings.kt`,拆分在 `Strings` / `StringsA` … `StringsE` 之间,以保持文件可管理。

## 添加用户可见字符串

1. 在正确的 `Strings*` 拆分对象上添加属性,匹配周围风格。
2. 提供**全部 10 种语言。** 缺少完整覆盖的新宿主字符串是不完整的。
3. 像相邻代码那样从 Compose/UI 引用它。

```kotlin
// 示意 —— 匹配 Strings.kt 中实际的拆分对象风格
val myNewLabel: String
    get() = when (current) {
        Lang.ZH -> "我的标签"
        Lang.EN -> "My label"
        Lang.AR -> "..."
        // ... 全部 10 种
    }
```

## 规则

- 优先在**现有拆分对象**上添加属性;不要创建新的本地化机制。
- 阿拉伯文必须完整 RTL —— 验证布局正确镜像。
- 不要在 Compose 界面中硬编码用户可见文本;始终经由 `Strings`。
