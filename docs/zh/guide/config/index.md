# 应用配置

各应用选项在[编辑通用配置](/zh/guide/app-actions/edit-common-config/)中配置 —— 一长卷能力卡片。本页是导航图;**卡片页**有详解。

## 按编辑器卡片

完整的逐卡片列表见[编辑通用配置](/zh/guide/app-actions/edit-common-config/)。

## 按主题

- [网络与反审查](/zh/guide/config/network) —— DNS、代理、TLS 指纹、CORS、故障转移。
- [隐私与加固](/zh/guide/config/privacy) —— 激活、去广告、伪装、加密。
- [外观](/zh/guide/config/appearance) —— 工具栏、全屏、方向、启动画面、BGM。
- [本地服务运行时](/zh/guide/config/runtimes) —— Node/PHP/Python/Go/WordPress 基础设施。

## 核心 vs 通用

- **通用配置**(本节)—— 每个应用都有的共享卡片。
- **核心配置** —— 类型专属的来源/运行时设置;见[编辑核心配置](/zh/guide/app-actions/edit-core-config)和各[应用类型](/zh/guide/app-types/)。
