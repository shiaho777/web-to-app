# 应用列表

[我的应用](/zh/guide/main-screen/my-apps)的主体区域是一个可滚动的应用卡片列表(按选中的[分类](/zh/guide/main-screen/categories)和[搜索](/zh/guide/main-screen/search)过滤)。

## 卡片构成

每张卡片显示:

- **图标** —— 你选的图标,或类型专属默认图标。
- **名称** 与 **URL**(非网页类型则显示媒体路径 / 入口文件)。
- **类型标签** —— 网页、多站点、HTML、前端、PHP、WordPress、Node.js、Python、Go、媒体或画廊。
- **功能标签** —— 快速指示,如激活门控、去广告或公告(一次显示一个)。
- **健康状态点** —— 图标上来自 URL 健康监测的小状态点:绿(在线)、黄(慢)、红(离线)。
- **预览缩略图** —— 捕获的网站截图;点击重新捕获。

## 交互

| 手势 | 结果 |
| --- | --- |
| **点卡片** | 预览应用 |
| **点卡片上的 ⋮** | 打开[操作菜单](/zh/guide/app-actions/edit-core-config) |
| **向左滑动卡片** | 快速[删除](/zh/guide/app-actions/delete)(带确认) |
