# 创建按钮

[我的应用](/zh/guide/main-screen/my-apps)底部的 **创建** 按钮是新建应用的入口。

## 工作方式

- 点击 **创建**(＋ 图标旋转,标签切换为 **关闭**)。
- 按钮上方展开一个面板,含应用类型的 **3 列网格**。
- 点击某类型打开其创建流程。再次点击按钮(或某类型)收起。

默认网格是网页、多站点、HTML、离线包、前端和画廊。PHP、WordPress、Node.js、Python、Go 和媒体在[关于](/zh/guide/more-features/about)页打开 **高级功能** 后出现。
