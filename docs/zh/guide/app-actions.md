# 应用功能

[我的应用](/zh/guide/main-screen)上每张应用卡片都有一个 ⋮ 按钮,打开其操作菜单。(点击卡片本身是预览应用;向左滑动卡片是快速删除。)

## 操作菜单

| 操作 | 作用 |
| --- | --- |
| **编辑** *(网页类型)* | 打开完整编辑器。网页应用只有单一编辑入口。 |
| **编辑核心配置** *(其他类型)* | 打开类型专属编辑器(如 PHP 或 Node.js 表单)—— 运行时/来源设置。 |
| **编辑通用配置** *(其他类型)* | 打开共享编辑器 —— 外观、网络、隐私、导出。见[应用配置](/zh/guide/config/)。 |
| **创建快捷方式** | 在主屏幕上为生成的应用添加一个启动器快捷方式。 |
| **构建 APK** | 构建并签名 APK。见下文。 |
| **分享 APK** | 构建 APK,然后打开系统分享面板发送。 |
| **导出** | 把应用导出为可复用的项目模板(`.wtapkg` 形式),可在别处导入。 |
| **移动到分类** | 把应用移到另一个[分类](/zh/guide/main-screen#category-tabs)。 |
| **删除** | 删除应用(带确认)。也可通过向左滑动卡片实现。 |

::: info 为什么有两个编辑入口?
非网页应用把设置拆分为 **核心**(类型专属:URL/运行时/来源)和 **通用**(共享:外观、网络、隐私、导出)。网页应用把所有东西放在一个编辑器里,所以只显示单一 **编辑**。
:::

## 构建 APK {#build-apk}

构建对话框修改 shell 模板、嵌入你的配置与内容、裁剪权限并签名。选项:

- **浏览器引擎** —— 系统 WebView 或 GeckoView。选择 GeckoView 会在首次使用时下载。
- **资源加密** —— 对打包的配置/HTML/媒体/BGM 使用 PBKDF2 + AES-256-GCM,可选自定义密码。启用它会激活运行时加固(反调试、反 Frida、DEX 篡改),并总是强制全量重建。
- **隔离** —— 按应用隔离存储、WebRTC、Canvas、Audio、WebGL、字体、头部和 IP 表面。
- **后台运行** —— 让应用的服务在后台保持存活。
- **通知** —— 定时/持久通知、URL 轮询前台服务、深度链接。
- **强制全量重建** —— 跳过增量缓存。
- **版本号** —— 当自定义包名已安装时,自动建议下一个 version code。

构建前会运行 **预检**,报告阻塞性错误。构建成功后可直接跳到 **AAB 导出** 以发布到 Google Play。

### 增量重建

重建是内容寻址的,有三种模式:

| 模式 | 适用时机 |
| --- | --- |
| `FULL` | 模板或身份变化;加密构建恒用此模式 |
| `CONTENT_OVERLAY` | 仅应用内容变化 |
| `REUSE_UNSIGNED` | 对先前构建的未签名 APK 重新签名 |

缓存键是内容哈希,绝不用时间戳。切勿把已签名或已改名的 APK 当作模板喂回。

## 签名与 AAB 导出 {#signing-aab-export}

- **密钥库** —— 创建、导入、导出、删除,以及查看证书指纹。支持 PKCS12/PFX/JKS/BKS,包括 Android Studio 上传密钥那种 store 密码与 key 密码不同的情况。
- **方案** —— V1/V2/V3 独立控制,旧证书自动回退,可自定义 V1 签名者文件名。
- **AAB 导出** —— 在 [Google Play](/zh/guide/more-features/system#google-play) 界面一键完成:按需自动构建 APK,转换为已签名的 AAB,把 `targetSdk` 重写到 Play 要求的级别(当前 36),并在本地生成 protobuf 元数据。中途可取消。

::: info 两个 targetSdk 值
生成的 APK 保持 `targetSdk` 28(为 fork+exec 运行时);AAB 导出器单独为 Play 重写。这是两条独立的路径。
:::

## 分享与导出

- **分享 APK** 先构建再通过系统分享面板分享 APK。如果构建或分享失败,会显示一份诊断报告(带构建日志尾部),可复制。
- **导出** 产生一个可复用的项目模板,可在另一台设备重新导入 —— 不同于构建一个可安装的 APK。

产物落在[文件管理](/zh/guide/more-features/system#file-manager)中。
