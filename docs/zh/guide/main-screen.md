# 主界面

**我的应用** 是主页。它有一个顶栏、一行分类标签、你的应用列表,以及底部的创建按钮。

## 顶栏

从左到右,顶栏显示界面标题(**我的应用**)和四个操作:

| 操作 | 作用 |
| --- | --- |
| **暗亮色** | 切换深色模式。切换时会从按钮处播放 circular "主题揭示" 动画。选择会被持久化。 |
| **语言** | 打开语言选择器。宿主界面提供 10 种语言;切换立即生效。 |
| **搜索** | 在标题栏切换出一个内联搜索框,按名称/URL 过滤应用。再点一次(✕)清除。 |
| **更多(⋮)** | 打开全局工具下拉菜单。见[更多功能](/zh/guide/more-features/ai-tools)。 |

## 分类标签 {#category-tabs}

顶栏下方的一行标签让你把应用整理进 **分类**。你可以添加分类(起名并选图标)、编辑或删除。选中某个标签会把应用列表过滤到该分类。应用可从其操作菜单在分类间移动(见[应用功能](/zh/guide/app-actions))。

## 应用列表

每个应用是一张卡片,显示:

- **图标** —— 你选的图标,或类型专属默认图标。
- **名称** 与 **URL**(非网页类型则显示媒体路径 / 入口文件)。
- **类型标签** —— 网页、多站点、HTML、前端、PHP、WordPress、Node.js、Python、Go、媒体、画廊等。
- **功能标签** —— 快速指示,如激活门控、去广告或公告。
- **健康状态点** —— 图标上的小状态点:绿(在线)、黄(慢)、红(离线),来自 URL 健康监测。
- **预览缩略图** —— 捕获的网站截图(点击重新捕获)。

交互:

- **点卡片** → 预览应用。
- **点卡片上的 ⋮** → 各应用操作菜单([应用功能](/zh/guide/app-actions))。
- **向左滑动卡片** → 快速删除(带确认)。

## 创建按钮

底部的 **创建** 按钮展开一个面板,含 12 种[应用类型](/zh/guide/create-app)的 3 列网格。点击某类型即开始其创建流程。

## 空状态

还没有应用时,列表显示一个空状态,带提示和一个 **创建** 快捷按钮。
