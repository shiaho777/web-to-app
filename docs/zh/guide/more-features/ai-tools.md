# 更多 · AI 工具

[我的应用](/zh/guide/main-screen)右上角的 **⋮** 菜单打开全局工具。第一组是 AI。

## AI 编程 {#ai-coding}

应用内的提示词驱动编码助手。它能生成网页应用、扩展模块、油猴脚本、MV3 扩展和本地运行时项目。

- **会话** —— 每段对话有标题和历史。
- **技能** —— 内置技能(debug、explain、optimize、refactor、i18n、imagery,加上各技术栈的 `*-app` 和模块技能)引导生成。你可以在技能编辑器中编辑或添加技能。
- **计划模式** —— 可先提出计划,等你批准后再应用改动。
- **韧性** —— 遇到 429/5xx 自动退避重试。

AI 编程使用 **AI 设置** 中配置的模型。

## AI 设置

配置 AI 编程所用的 AI 后端:

- **API 密钥** —— 添加提供商 API 密钥(在设备上安全存储)。
- **已保存模型** —— 管理可供选择的模型,带价格参考。

::: tip
AI 编程生成的是*源码*(模块、油猴脚本、前端应用、运行时项目)。要安装生成的扩展,请通过[扩展模块](/zh/guide/more-features/dev-tools#extension-modules)流程保存。
:::
