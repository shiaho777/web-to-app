# 双栏文件管理器

主屏幕现在打开双栏文件工作区。通过 Android 系统选择器为每个面板选择文件夹，访问权限会保存在本机。

## 功能

- **独立目录** —— 分别浏览和搜索两个面板中的位置。
- **文件操作** —— 多选、跨面板复制或移动、新建文件夹、重命名、删除和比较文件。
- **文本编辑** —— 编辑不超过 1 MiB 的受支持文本文件；保存时会在应用私有目录中保留备份。
- **可调整布局** —— 宽屏并排显示，手机上下堆叠；拖动分隔线可调整大小或交换面板。
- **我的应用** —— 通过顶部栏返回应用列表。

## 说明

- Android 会要求你为每个文件夹授予访问权限；所选位置和权限会保存在本机。
- [⋮ → 文件管理](/zh/guide/main-screen/more)仍可用于管理 APK/AAB 构建产物、构建日志和应用生成的文件。
- 复制和移动要求两个面板都具有写入权限。移动需要确认，并且只会在复制成功后删除源文件。
