# 文件管理

构建产物和用户文件的统一入口。从 [⋮ → 文件管理](/zh/guide/main-screen/more) 打开。

## 功能

- **浏览** —— APK 构建、AAB 导出、应用克隆、构建日志,以及用户文件目录。
- **搜索** —— 按名称过滤文件。
- **操作** —— 查看、打开、复制、分享、安装(APK)和删除。
- **多选** —— 选择多个文件进行批量删除/清理。
- **清理** —— 清空某个目录(带确认)。
- **构建日志查看器** —— 只读的构建日志查看器(大日志会截断显示)。

## 说明

- 安装会启动系统包安装器;失败会被报告。
- [构建 APK](/zh/guide/app-actions/build-apk) 和 [AAB 导出](/zh/guide/more-features/google-play)的构建产物落在这里。
