# 更多 · 开发工具

**⋮** 菜单中的开发工具组。

## 扩展模块 {#extension-modules}

管理在生成的应用中运行的扩展:内置模块、自定义 JS/CSS 模块、油猴脚本和 MV3 Chrome 扩展。

- **列表与开关** —— 按应用启用/禁用已安装的扩展。
- **编辑器** —— 创建或编辑模块(清单、JS、CSS、配置项、面板)。见 [JS 模块](/zh/extensions/js-module)。
- **市场** —— 浏览社区模块市场。见[发布到市场](/zh/extensions/publish)。
- **浏览器扩展** —— 实时搜索 Chrome 网上应用店并安装 MV3 扩展。见 [Chrome MV3](/zh/extensions/chrome-mv3)。
- **AI 开发者** —— 跳转到 [AI 编程](/zh/guide/more-features/ai-tools#ai-coding)生成扩展。

## 应用修改器 {#app-modifier}

重打包一个*已安装*的应用:快捷方式伪装,或带 manifest/资源修改和重签名的真实二进制克隆。

- 选择一个已安装应用,然后修改其图标、名称和包身份。
- 修改后的 APK 在二进制层面被打补丁并重签名。
- 用于图标/名称/包名实验和重打包研究 —— 请在拥有相应权利的前提下使用。

## Linux 环境 {#linux-environment}

管理服务端运行时应用类型(Node.js、PHP、Python)和前端构建所用的设备端工具链与依赖。

- 安装和更新运行时工具链。
- 管理共享依赖。
- **重置环境** 以从损坏状态恢复。

运行时类型在需要安装时,会从其创建界面链接到这里。

## 运行时管理 {#runtime-management}

下载并管理运行时二进制本身:

- **PHP 运行时**、**WordPress 核心**、**Node.js 运行时**、**Python 运行时**。
- 各自在首次使用时下载(大型下载使用延长超时的客户端),并缓存以供多个应用复用。

## 端口管理器 {#port-manager}

在所有生成的应用间协调本地服务运行时所用的端口。

- 查看哪些端口被占用、被哪个运行时占用。
- 冲突策略 —— `REASSIGN`、`AUTO_KILL` 或 `ALERT`。
- 扫描冲突;运行时通过端口管理器分配,并在停止时释放。
