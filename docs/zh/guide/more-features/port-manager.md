# 端口管理

在所有生成的应用间协调本地服务运行时所用的端口。从 [⋮ → 端口管理](/zh/guide/main-screen/more) 打开。

## 功能

- **服务列表** —— 查看哪些端口被占用、所属进程和延迟。
- **结束** —— 停止单个服务,或 **全部结束**。
- **自动刷新** —— 保持列表最新。
- **端口范围** —— 查看配置的端口范围。
- **复制端口 / 打开** —— 每条目快捷操作。
- **过滤** —— 显示全部服务或过滤;专门检测 WebToApp 应用。
- **状态** —— 响应中 / 无响应指示。

## 冲突策略

当运行时需要的端口被占用时,应用的配置策略:

- `REASSIGN` —— 选另一个端口。
- `AUTO_KILL` —— 停止冲突的服务。
- `ALERT` —— 通知并由你决定。

## 说明

运行时通过端口管理器分配,并在停止时释放端口,因此端口不会在应用间泄漏。
