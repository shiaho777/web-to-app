# 关于

应用信息与数据工具。从 [⋮ → 关于](/zh/guide/main-screen/more) 打开。

## 功能

- **关于** —— 版本、当前语言和项目链接。
- **数据备份 / 恢复** —— 备份和恢复你的项目与应用数据。
- **检查更新** —— 检查是否有更新版本的构建器(显示当前版本及是否有可用更新)。
- **法律免责声明** —— 涵盖允许用途和责任的重要声明。

## 说明

- 在重大更改前或更换设备时,使用 **数据备份**。
