# 运行时管理

下载并管理服务端运行时应用所使用的运行时二进制。从 [⋮ → 运行时管理](/zh/guide/main-screen/more) 打开。

## 管理的运行时

- **PHP 运行时**
- **WordPress 核心**
- **Node.js 运行时**
- **Python 运行时**
- **Go 运行时**

## 功能

- **按运行时状态** —— 就绪 / 缺失,带下载进度。
- **全部下载** —— 一次性获取所需的全部。
- **暂停 / 继续 / 取消** —— 控制单个下载。
- **清除** —— 移除某个运行时或清除全部(带确认)。
- **过滤** —— 显示全部、仅缺失或仅就绪。
- **镜像** —— 自动选择镜像,带国内镜像选项。

## 说明

- 大型下载使用延长超时的下载客户端。
- 运行时在首次使用时下载,并缓存以供多个应用复用。
- 工具链和构建依赖见 [Linux 环境](/zh/guide/more-features/linux-environment)。
