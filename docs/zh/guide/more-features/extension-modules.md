# 管理插件

管理在生成的应用中运行的插件。从 [⋮ → 管理插件](/zh/guide/main-screen/more) 打开。

## 能管理什么

内置插件、自定义 HCJ 包、油猴脚本和 MV3 Chrome 扩展——全部在同一个统一面上。

## 功能

- **列表与开关** —— 每一行有一个开关。打开表示这个插件已启用。应用打开了插件、又没有单独挑一份清单时，就运行这里已启用的插件。应用里单独挑过的清单仍然只运行那一份。新添加的插件默认打开。内置插件要手动打开才会启用。
- **编辑器** —— 创建或编辑插件：清单、JavaScript、CSS 和 `panel.html` 界面。见 [HCJ 插件](/zh/extensions/js-module)。
- **市场** —— 浏览社区插件市场。见[发布到市场](/zh/extensions/publish)。
- **浏览器扩展** —— 实时搜索 Chrome 网上应用店并安装 MV3 扩展。见 [Chrome MV3](/zh/extensions/chrome-mv3)。
- **宿主形态** —— 选择插件入口的呈现方式（工具栏按钮/悬浮句柄/菜单），以及面板的承载形态（底部抽屉/悬浮窗/全屏）。悬浮柄在启用多个插件时从该位置扇形展开（只有一个则直接打开该插件；一个都没有则仍打开列表）。
- **网址切换** —— 内置插件，保存一组网址并切换当前页。任意应用类型都能挂。第一次打开是空的，添加网址（或当前页），点一行就跳转。长按一行拖动可改顺序。当前打开的页会标出来。重复添加不会再跳走。
- **导入/导出** —— `.hcj` 插件包、`.user.js` 油猴脚本、`.zip`/`.crx` 扩展。
- **AI 开发者** —— 跳转到 [Agent](/zh/guide/more-features/agent) 生成插件。
