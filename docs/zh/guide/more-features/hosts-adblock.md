# Hosts 拦截

带 cosmetic 过滤的 hosts 规则去广告器。从 [⋮ → Hosts 拦截](/zh/guide/main-screen/more) 打开。

## 功能

- **生效规则数** —— 查看已加载的拦截规则数量。
- **来源** —— 管理过滤订阅:下载、从文件或 URL 导入,或删除来源。
- **内置列表** —— 20 个社区过滤列表(EasyList、uBlock Origin、AdGuard、AdAway,外加 8 个语言专属列表)。
- **搜索** —— 查找特定规则。
- **清除** —— 移除全部已加载规则(带确认)。

## Cosmetic 过滤

除主机拦截外,基于 MutationObserver 的 cosmetic 过滤器会隐藏被 cosmetic 规则匹配的元素。

## 说明

- 去广告同时贯通预览与导出:宿主去广告器服务预览,编译后的规则集随生成的 APK 一起发布。
- 在[隐私](/zh/guide/config/privacy)中按应用配置去广告。
