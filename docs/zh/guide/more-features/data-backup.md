# 数据备份

导出或导入所有应用数据——包括配置、图标、启动画面、BGM 等资源文件。从 [⋮ → 数据备份](/zh/guide/main-screen/more) 打开。

## 工作方式

- **导出数据** —— 把所有应用的配置和资源文件打包成一个 `.zip` 备份。
- **导入数据** —— 恢复先前导出的 `.zip`。导入的应用以新条目添加,不会覆盖现有数据。
- 若恢复了本地设置文件,应用会先询问再重启使其生效。

## 何时使用

在设备之间迁移项目,或在重大更新前做一份快照。

## 说明

- 导入是新增而非合并——更新应用前建议先导出备份。
- 备份是普通 `.zip` 文件,可存放在任意位置。

## 源码导出包

对单个应用使用「导出源码」得到的压缩包,既是一份 Android Studio 工程,也是这个应用可用的 WebToApp 备份。其中包含 `apps.json`(完整项目配置)、`resources/`(图标与媒体)、`local/files/`(HTML、前端以及 Node.js / PHP / Python / Go / WordPress 的项目源码)。重装 WebToApp 后,在「导入数据」中选择这个 zip 即可恢复该应用。

源码包只含这一个应用,不含全局设置、扩展模块、广告拦截规则与签名密钥库;需要整机快照请使用「导出数据」。旧版本生成的源码包没有 `apps.json`,无法导入,请用新版重新导出一次。

## 卸载之前

WebToApp 关闭了 Android 系统备份(`allowBackup="false"`),因此卸载构建器会永久删除所有项目、源码文件与配置。在卸载、换机,或让手机安全软件处理本应用之前,请先导出备份。被杀毒软件「卸载」的操作无法撤销。
