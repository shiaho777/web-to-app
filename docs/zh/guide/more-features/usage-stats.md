# 使用统计

各应用的分析与 URL 健康监测。从 [⋮ → 使用统计](/zh/guide/main-screen/more) 打开。

## 使用统计

- **启动次数** —— 总计和各应用的启动次数。
- **活跃应用** —— 有多少应用被使用过。
- **平均会话** 与 **上次会话** —— 会话时长指标。
- **排行** —— 按启动次数或最近使用排名。
- **排序** —— 按启动次数或最近。
- **清除全部** —— 重置统计(带确认)。

## URL 健康

- **检查** —— 测试某个应用的目标 URL,或检查全部。
- **状态** —— 在线 / 慢 / 离线 / 未知,带响应时间和上次检查时间戳。
- 同样的状态会以[健康状态点](/zh/guide/main-screen/app-list)显示在应用卡片上。

## 说明

统计在设备上本地收集。
