# Linux 环境

管理服务端运行时应用类型([Node.js](/zh/guide/app-types/nodejs)、[PHP](/zh/guide/app-types/php)、[Python](/zh/guide/app-types/python))和[前端](/zh/guide/app-types/frontend)构建所用的设备端工具链与依赖。从 [⋮ → Linux 环境](/zh/guide/main-screen/more) 打开。

## 功能

- **工具链** —— 安装和更新每个运行时所需的构建工具(显示为就绪 / 未安装 / 安装中 / 下载中 / 失败)。
- **运行时** —— 直接安装 PHP 和 Python 运行时。
- **Composer** —— 安装 Composer(需要先有 PHP)。
- **前端构建** —— 打包器就绪后,环境可构建前端项目。
- **缓存** —— 查看缓存大小、清除缓存,以及重置环境以从损坏状态恢复。

## 说明

- 运行时类型的创建界面在需要安装时会自动链接到这里。
- 运行时*二进制*本身(下载、镜像)见[运行时管理](/zh/guide/more-features/runtime-management)。
