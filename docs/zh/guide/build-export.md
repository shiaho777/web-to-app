# 构建与导出

WebToApp 完全在设备上构建并签名 APK,还能将其转换为 Google Play 级 AAB。

## 构建管线

点击 **构建 APK** 时,构建器会:

1. **加载 shell 模板** —— 唯一的标准 `webview_shell.apk`(运行时,从宿主 `app/` 源码同步而来)。
2. **修改二进制资源** —— 在二进制 AXML manifest 和 ARSC 资源表中重写包名、图标、标签和版本。
3. **裁剪权限** —— 从模板 manifest 中移除未使用的权限。
4. **嵌入配置与内容** —— 把你的 `WebApp` 配置序列化为 assets JSON(`app_config.json`),并打包应用内容(HTML、媒体、运行时资源)。
5. **签名** —— 通过 `apksig` 应用 V1/V2/V3 签名。

### 增量重建

重建通过内容寻址缓存实现增量,有三种模式:

| 模式 | 适用时机 |
| --- | --- |
| `FULL` | 模板或身份变化;加密构建恒用此模式 |
| `CONTENT_OVERLAY` | 仅应用内容变化 |
| `REUSE_UNSIGNED` | 对先前构建的未签名 APK 重新签名 |

缓存键是**内容哈希**,绝不用时间戳。加密构建总是强制全量重建。

::: warning
切勿把已签名或已改名的 APK 当作模板喂回全量构建路径 —— 会破坏缓存键和身份修改。
:::

## 签名

在导出设置中配置:

- **密钥库管理** —— 创建、导入、导出、删除,以及查看证书指纹。支持 PKCS12/PFX/JKS/BKS 导入,包括 Android Studio 上传密钥那种 store 密码与 key 密码不同的情况。
- **签名方案** —— V1、V2、V3 独立控制,旧证书自动回退。可自定义 V1 签名者文件名,用于 `META-INF/<name>.SF` / `.RSA`。

## 资源加密

启用加密后,用 **PBKDF2 + AES-256-GCM** 保护打包的配置、HTML、媒体和 BGM。你可以提供一个比包名/证书派生密钥更强的自定义加密密码。开启加密后,运行时加固(反调试、反 Frida、DEX 篡改检查)随之激活,威胁响应可配置:仅记录日志、静默退出或随机崩溃。

加密构建总是从头重建。

## Google Play AAB 导出

一键 AAB 导出:

1. 按需自动构建 APK。
2. 转换为已签名的 AAB,并把 `targetSdk` 重写到 Play 要求的级别(当前为 36)。
3. 在本地生成 protobuf 元数据。

构建中途可取消。

::: info 为什么有两个 targetSdk?
生成的 APK 保持较低的 `targetSdk`(28),以便能从应用存储 fork+exec 原生运行时。AAB 导出器则单独重写 `targetSdk` 以满足 Play 商店政策。这是两条独立的路径。
:::

## 性能选项

图片压缩、WebP 转换、代码压缩、懒加载、DNS 预取和预加载提示 —— 均按应用开关。

## 文件管理器

一个界面即可查看、分享、安装、打开和清理构建产物(APK 构建、AAB 导出、应用克隆、构建日志)以及用户文件目录,并带只读的构建日志查看器。
