# 分享 APK

构建 APK,然后打开系统分享面板发送。点击应用卡片上的 ⋮,再点 **分享 APK**。

## 工作方式

1. WebToApp 构建 APK(显示"构建中"提示)。
2. 成功后,报告所用的增量构建模式。
3. 系统分享面板打开,附带 APK,可发送到任意应用。

## 如果失败

会显示一份诊断报告,含:

- 失败阶段和原因,
- 项目详情,
- 构建日志尾部,
- 最近日志。

你可以复制报告用于排查。

## 说明

- 只构建不分享,用[构建 APK](/zh/guide/app-actions/build-apk)。
- 导出可复用项目而非 APK,用[导出](/zh/guide/app-actions/export-apk)。
