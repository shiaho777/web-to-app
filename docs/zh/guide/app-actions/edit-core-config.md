# 编辑核心配置

打开应用的 **类型专属** 设置 —— 其来源与运行时配置。点击应用卡片上的 ⋮,再点 **编辑核心配置**。

## 编辑什么

类型专属的创建表单,复用为编辑器:

| 应用类型 | 核心配置涵盖 |
| --- | --- |
| [网页](/zh/guide/app-types/web) | *(网页有单一合并编辑器 —— 见说明)* |
| [多站点](/zh/guide/app-types/multi-web) | 站点、布局、按站点设置 |
| [HTML](/zh/guide/app-types/html) | 文件、入口文件、加载模式、端口 |
| [前端](/zh/guide/app-types/frontend) | 构建输出、框架 |
| [PHP](/zh/guide/app-types/php) | 项目、启动命令 |
| [WordPress](/zh/guide/app-types/wordpress) | 站点、主题、插件 |
| [Node.js](/zh/guide/app-types/nodejs) | 项目、启动命令 |
| [Python](/zh/guide/app-types/python) | 项目、启动命令 |
| [Go](/zh/guide/app-types/go) | 模块、构建/运行 |
| [媒体](/zh/guide/app-types/media) | 媒体文件、播放 |
| [画廊](/zh/guide/app-types/gallery) | 媒体、视图、播放 |

## 说明

- **网页应用不显示此入口** —— 它们有单一的 **编辑**,涵盖一切,因为网页配置不拆分。
- 共享选项(外观、网络、隐私、导出)用[编辑通用配置](/zh/guide/app-actions/edit-common-config)。
