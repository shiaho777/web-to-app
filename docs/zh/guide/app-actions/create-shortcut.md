# 创建快捷方式

在主屏幕上为生成的应用添加一个启动器快捷方式。点击应用卡片上的 ⋮,再点 **创建快捷方式**。

## 工作方式

- WebToApp 请求启动器为应用固定一个快捷方式。
- 成功后,显示确认,快捷方式出现在主屏幕上。

## 可能的结果

| 结果 | 含义 |
| --- | --- |
| **成功** | 快捷方式已创建。 |
| **待定** | 启动器需要确认;按提示操作。 |
| **需要权限** | 启动器需要"安装快捷方式"权限 —— 授予后重试。 |
| **错误** | 创建失败;消息说明原因。 |

## 说明

快捷方式直接启动生成的应用,独立于构建器。
