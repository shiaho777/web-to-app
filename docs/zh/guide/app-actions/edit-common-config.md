# 编辑通用配置

打开每个应用都有的 **共享** 配置 —— 外观、网络、隐私和导出。点击应用卡片上的 ⋮,再点 **编辑通用配置**。

## 编辑什么

通用编辑器是一长卷能力卡片:

- **基本信息** —— 名称、图标。
- **外观** —— 工具栏、全屏、方向、启动画面、背景音乐。见[外观](/zh/guide/config/appearance)。
- **网络** —— DNS、代理、TLS 指纹、ECH、CORS。见[网络](/zh/guide/config/network)。
- **隐私** —— 激活、去广告、指纹伪装、加密。见[隐私](/zh/guide/config/privacy)。
- **扩展** —— 附加的模块、油猴脚本、MV3 扩展。见[扩展](/zh/extensions/)。
- **行为** —— 公告、翻译、自启动。
- **导出与权限** —— 包名、版本、签名、运行时权限。见[构建 APK](/zh/guide/app-actions/build-apk)。

逐卡片的完整索引在[应用配置](/zh/guide/config/)。

## 说明

- 对 **网页** 应用,这简称为 **编辑**(网页有一个合并编辑器)。
- 类型专属的来源/运行时设置用[编辑核心配置](/zh/guide/app-actions/edit-core-config)。
