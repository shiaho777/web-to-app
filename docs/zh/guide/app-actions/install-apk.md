# 安装 APK

从首页 ⋮ 菜单打开 APK 安装页面，可检查并安装设备存储中的 APK。

## 选择并检查

使用 Android 系统文件选择器选择 APK。WebToApp 会检查文件是否为有效的软件包，并显示包名、应用名称、版本和文件大小。

## 安装

点击 **安装** 后会打开 Android 系统安装程序。如果 Android 要求授予安装未知应用的权限，请在系统设置中授权，然后返回 WebToApp。系统安装程序需要用户确认；WebToApp 不会静默安装软件包。

是否可安装及安装结果取决于 Android 策略、所选软件包和设备。若安装失败，请查看系统安装程序显示的具体原因。
