# 导出

把应用导出为 **可复用的项目模板**,可在另一台设备导入。点击应用卡片上的 ⋮,再点 **导出**。

## 工作方式

- WebToApp 把应用的配置(和内容)打包成一个便携模板。
- 成功后,报告输出路径。

## 导出 vs 构建 vs 分享

| 操作 | 产生 |
| --- | --- |
| **导出** | 可复用的项目模板(可重新导入) |
| [构建 APK](/zh/guide/app-actions/build-apk) | 可安装的已签名 APK |
| [分享 APK](/zh/guide/app-actions/share-apk) | 经分享面板发送的已构建 APK |

## 说明

- 用导出在设备间迁移应用的*定义*;用构建/分享分发可安装的 APK。
