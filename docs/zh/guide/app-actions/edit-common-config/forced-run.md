# 强制运行设置

配置生成应用的强制运行行为。

**位置:**[编辑通用配置](/zh/guide/app-actions/edit-common-config/)编辑器中的 **强制运行** 卡片(由 `ForcedRunConfig` 支撑)。

## 选项

配置应用如何保持自身运行(强制运行策略),作为应用运行时配置的一部分导出。

## 说明

- 强制运行是技术演示功能 —— 请在用户知情同意下使用。
- 它与后台运行和自启动选项相互作用;见[自启动设置](/zh/guide/app-actions/edit-common-config/auto-start)和 [APK导出配置](/zh/guide/app-actions/edit-common-config/apk-export)。
