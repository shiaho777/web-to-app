# 网址/网页

WebView 加载的目标。这是网页类应用类型的主要字段。

**位置:**[编辑通用配置](/zh/guide/app-actions/edit-common-config/)编辑器顶部的 **基本信息** 卡片。

## 选项

- **目标 URL** —— 要加载的网站(例如 `https://example.com`)。

## PWA 分析(网页类型)

对于 `WEB` 应用,**PWA 分析** 区可以检查目标并检测渐进式 Web 应用 / 离线缓存提示,帮助你决定离线策略。

## 说明

- 对于非网页类型,"目标"改为类型专属的来源(本地文件夹、项目、媒体等)—— 在[编辑核心配置](/zh/guide/app-actions/edit-core-config)中配置。
- 故障转移镜像 URL(目标不可达时自动回退)在[高级设置](/zh/guide/app-actions/edit-common-config/advanced-settings)中配置。
