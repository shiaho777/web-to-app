# 背景音乐

在生成的应用中播放背景音乐,带同步歌词。

**位置:**[编辑通用配置](/zh/guide/app-actions/edit-common-config/)编辑器中的 **背景音乐** 卡片。

## 选项

- **启用** —— 打开背景音乐(`bgmEnabled`)。
- **播放列表** —— 添加音乐曲目;支持同步 **LRC 歌词** 与歌词动画。
- **播放模式** —— 循环、顺序或随机(`BgmPlayMode`)。
- **歌词样式** —— 自定义字体、颜色、描边和阴影。
- **在线搜索** —— 在线搜索音乐。

## 说明

- BGM 音频文件被打包进导出的 APK(并可加密)。
