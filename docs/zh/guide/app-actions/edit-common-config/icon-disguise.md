# 图标与应用

伪装生成应用在设备上的图标和名称 —— 多启动器图标、"图标风暴"模式和随机名称。

**位置:**[编辑通用配置](/zh/guide/app-actions/edit-common-config/)编辑器中的 **图标与应用** 卡片(由 `DisguiseConfig` 支撑)。

## 选项

- **启用** —— 打开图标/应用伪装。
- **多启动器图标** —— 创建多个启动器条目(`multiLauncherIcons`);一个影响等级指示器显示该设置的激进程度。
- **图标风暴模式**(`iconStormMode`)—— 例如 `NORMAL` 和更强的模式。
- **随机名称** —— 随机化生成应用的名称(`randomizeNames`)。
- **自定义名称前缀** —— 生成名称的前缀(`customNamePrefix`)。

## 说明

- 这影响导出应用的启动器呈现;基础图标和名称在[应用图标](/zh/guide/app-actions/edit-common-config/app-icon)和[应用名称](/zh/guide/app-actions/edit-common-config/app-name)中设置。
- 图标风暴是演示功能 —— 请在用户知情同意下使用。
