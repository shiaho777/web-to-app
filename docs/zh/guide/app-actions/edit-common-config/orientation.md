# 屏幕方向

锁定或约束应用的屏幕方向。

**位置:**[编辑通用配置](/zh/guide/app-actions/edit-common-config/)编辑器中的 **屏幕方向** 卡片。

## 选项

- **横屏模式** —— 快速切换强制横屏(`landscapeMode`)。
- **方向模式** —— 细粒度控制(`orientationMode`):
  - `PORTRAIT`(竖屏)
  - `LANDSCAPE`(横屏)
  - `REVERSE_PORTRAIT`(反向竖屏)
  - `REVERSE_LANDSCAPE`(反向横屏)
  - `SENSOR_PORTRAIT`(传感器竖屏)
  - `SENSOR_LANDSCAPE`(传感器横屏)

## 说明

- 选择横屏模式会相应设置 `landscapeMode`;传感器模式在约束内跟随设备。
- 启动画面和媒体有自己的方向设置(见[启动动画](/zh/guide/app-actions/edit-common-config/splash))。
