# 编辑通用配置

**编辑通用配置** 是 WebToApp 的核心。它打开每个应用都有的共享编辑器 —— 一长卷能力卡片,涵盖外观、行为、网络、隐私、扩展和打包。点击应用卡片上的 ⋮,再点 **编辑通用配置**(网页应用此入口简称为 **编辑**)。

本节按编辑器中出现的顺序,**逐卡片** 详解每一张。
