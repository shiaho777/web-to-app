# 长按菜单

配置长按页面内容时显示的上下文菜单。

**位置:**[编辑通用配置](/zh/guide/app-actions/edit-common-config/)编辑器中的 **长按菜单** 卡片。

## 选项

- **样式**(`longPressMenuStyle`):
  - `DISABLED` —— 无长按菜单(同时禁用)
  - `SIMPLE`
  - `FULL`
  - `IOS`
  - `FLOATING`
  - `CONTEXT`

## 说明

- 选择 `DISABLED` 以外的任意样式都会启用长按菜单(`longPressMenuEnabled`)。
