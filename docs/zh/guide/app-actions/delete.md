# 删除

移除一个应用。有两种方式:

- **操作菜单** —— 点击应用卡片上的 ⋮,再点 **删除**。
- **滑动** —— 向左滑动卡片,露出删除入口。

## 工作方式

两种方式都会在删除前要求 **确认**。确认后,应用从[我的应用](/zh/guide/main-screen/my-apps)永久移除。

## 说明

- 删除会从构建器移除应用的定义。你已经构建的 APK 仍留在[文件管理](/zh/guide/more-features/file-manager)中,直到你清理。
- 想整理而不删除,用[移动到分类](/zh/guide/app-actions/move-to-category)。
