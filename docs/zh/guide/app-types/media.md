# 媒体

由专门的媒体播放器播放的单图片或单视频应用。

## 适用场景

单图查看器、课程媒体,或循环播放的标牌式视频。

## 变体

- **图片** —— 全屏显示一张图片。
- **视频** —— 播放视频,可配置播放选项。

## 关键配置

- **来源** —— 打包进应用的本地媒体文件(可选加密)。
- **自动播放** —— 启动时开始播放(视频)。
- **循环** —— 重复播放。
- **音频** —— 启用或静音。
- **铺满屏幕** —— 裁剪铺满 vs 适应屏幕。

## 说明

- 预览直接启动媒体播放器 activity(而非 WebView)。
- 媒体*集合*请用[画廊](/zh/guide/app-types/gallery)。
