# 网页内容类型

这些类型包装或打包网页内容。它们不运行服务端运行时 —— WebView 加载远程 URL 或本地文件。

## Web {#web}

把远程 URL 套进 WebView。

- **引擎** —— 默认系统 WebView;可选 GeckoView(首次使用下载,ECH 必需)。
- **关键配置** —— 目标 URL、User-Agent、桌面模式、JS/CSS 注入(document-start/end/idle)、弹窗处理(同窗口 / 外部 / 弹窗 / 拦截)。
- **适用** —— 落地页、工具、仪表盘、文档、内部系统。

网页类型也是配置最丰富的:其编辑器暴露完整的能力卡片(全屏、启动画面、去广告、DNS、伪装等)。见[应用配置](/zh/guide/config/)。

## 多站点 {#multi-web}

把多个站点合并到一个应用。

- **布局** —— 标签、卡片、信息流或抽屉。
- **按站点** —— 每个站点可有自己的图标、主题色、提取选择器和刷新间隔。
- **共享** —— 跨站点注入的公共 JS/CSS。
- **适用** —— 链接枢纽、门户、应用合集。

## HTML {#html}

把本地 HTML 打包进 APK,并从本地文件提供服务。

- **输入** —— 一个 HTML/CSS/JS 文件夹,或导入时解压的 `.zip`。
- **入口文件** —— 默认 `index.html`。
- **文件访问** —— 生成的应用获得 `allowFileAccess`,使纯文件加载可离线工作。
- **加载模式 / 端口** —— 可配置,本地服务器带端口冲突模式。
- **适用** —— 静态构建、离线 Web 应用。

## 离线包 {#offline-pack}

把一个在线站点抓取为自包含的离线包,然后像 HTML 应用一样包装。

- **抓取控制** —— 最大深度、跟随链接开关、最大文件数、最大总大小、跳过模式、超时,以及 CDN 资源下载开关。
- **重写** —— HTML/CSS/JS/图片/字体、`url()`、`srcset`、`@import`,带路径重写和同域/深度/大小限制。
- **适用** —— 把网站归档为离线使用。

## 前端 {#frontend}

打包一个*已构建*的前端项目(React、Vue、Vite 等的生产输出)。

- **输入** —— 构建输出目录;框架被识别/选择。
- **工具链** —— 当需要设备端构建步骤时,链接到 [Linux 环境](/zh/guide/more-features/dev-tools#linux-environment)。
- **适用** —— React、Vue、Vite 生产构建、SPA。

::: info HTML vs 前端 vs 离线包
- **HTML** —— 你已经有静态文件。
- **前端** —— 你有一个框架项目,打包其构建输出。
- **离线包** —— 你从一个远程 URL 开始,把它抓取下来。
:::
