# Language

The language button in the [My Apps](/guide/main-screen/my-apps) top bar opens the language selector for the builder UI.

## Supported languages

The host UI is fully localized into **10 languages**:

Chinese · English · Arabic (full RTL) · Portuguese · Spanish · French · German · Russian · Japanese · Korean

## How it works

- Tap the language button and pick a language.
- The change applies **immediately** across the whole builder UI; a confirmation snackbar appears.
- Arabic switches the layout to full right-to-left.

## Scope

This is the **builder's** UI language. The language of the apps you *generate* is configured separately per app (and a generated app can also offer an in-page [translation overlay](/guide/config/appearance)).
