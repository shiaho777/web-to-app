# Search

The magnifier button in the [My Apps](/guide/main-screen/my-apps) top bar toggles an inline search field.

## How it works

- Tap 🔍 to replace the title bar with a search field.
- Type to **filter the app list** by app name or URL — the list updates as you type.
- Tap ✕ to clear the query and close search.

Search only filters the visible list; it doesn't modify your apps. It works within the currently selected [category](/guide/main-screen/categories).
