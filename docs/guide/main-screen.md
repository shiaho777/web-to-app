# Main Screen

**My Apps** is the home screen. It has a top bar, a category tab row, your app list, and a create button at the bottom.

## Top bar

From left to right, the top bar shows the screen title (**My Apps**) and four actions:

| Action | What it does |
| --- | --- |
| **Dark / Light** | Toggles dark mode. The switch plays a circular "theme reveal" animation from the button. The choice persists. |
| **Language** | Opens the language selector. The host UI is available in 10 languages; switching applies immediately. |
| **Search** | Toggles an inline search field in the title bar to filter your apps by name/URL. Tap again (✕) to clear. |
| **More (⋮)** | Opens the dropdown menu of global tools. See [More Features](/guide/more-features/ai-tools). |

## Category tabs

Below the top bar, a tab row lets you organize apps into **categories**. You can add a category (give it a name and icon), edit, or delete one. Selecting a tab filters the app list to that category. Apps can be moved between categories from their action menu (see [App Actions](/guide/app-actions)).

## App list

Each app is a card showing:

- **Icon** — your chosen icon, or a type-specific default.
- **Name** and **URL** (or media path / entry file for non-web types).
- **Type chip** — Web, Multi-Web, HTML, Frontend, PHP, WordPress, Node.js, Python, Go, Media, Gallery, etc.
- **Feature chips** — quick indicators such as activation gating, ad blocking, or announcement.
- **Health dot** — a small status dot on the icon: green (online), amber (slow), red (offline), from URL health monitoring.
- **Preview thumbnail** — a captured screenshot of the site (tap to re-capture).

Interactions:

- **Tap the card** → preview the app.
- **Tap ⋮ on the card** → the per-app action menu ([App Actions](/guide/app-actions)).
- **Swipe the card left** → quick delete (with confirmation).

## Create button

The **Create** button at the bottom expands a panel with a 3-column grid of the 12 [app types](/guide/create-app). Tap a type to start its creation flow.

## Empty state

With no apps yet, the list shows an empty state with a hint and a **Create** shortcut button.
