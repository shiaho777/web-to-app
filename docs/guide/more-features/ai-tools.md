# More · AI Tools

The top-right **⋮** menu on [My Apps](/guide/main-screen) opens global tools. The first group is AI.

## AI Coding

A prompt-driven coding assistant inside the app. It can generate web apps, extension modules, userscripts, MV3 extensions, and local runtime projects.

- **Sessions** — each conversation has a title and history.
- **Skills** — built-in skills (debug, explain, optimize, refactor, i18n, imagery, plus stack-specific `*-app` and module skills) guide generation. You can edit or add skills in the skill editor.
- **Plan mode** — can propose a plan and wait for your approval before applying changes.
- **Resilience** — automatic retry with backoff on 429/5xx.

AI Coding uses the model configured in **AI Settings**.

## AI Settings

Configures the AI backend used by AI Coding:

- **API keys** — add provider API keys (stored securely on-device).
- **Saved models** — manage the models available for selection, with pricing reference.

::: tip
AI Coding generates *source* (modules, userscripts, front-end apps, runtime projects). To install a generated extension, save it through the [Extension Modules](/guide/more-features/dev-tools#extension-modules) flow.
:::
