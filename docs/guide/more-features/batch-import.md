# Batch Import

Import many apps at once. Open it from [⋮ → Batch Import](/guide/main-screen/more).

## How it works

- Paste or load a list of entries (for example, name + URL pairs).
- WebToApp parses the entries and creates the apps in bulk.
- A detailed import reports what was created.

## When to use

Migrating a collection of sites into WebToApp without creating each app by hand.

## Notes

- Imported apps are created with default configuration; refine each one afterward via [Edit Common Config](/guide/app-actions/edit-common-config/).
