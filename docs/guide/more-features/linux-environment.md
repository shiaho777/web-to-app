# Linux Environment

Manages the on-device toolchains and dependencies used by the server-runtime app types ([Node.js](/guide/app-types/nodejs), [PHP](/guide/app-types/php), [Python](/guide/app-types/python)) and [Frontend](/guide/app-types/frontend) builds. Open it from [⋮ → Linux Environment](/guide/main-screen/more).

## Features

- **Toolchains** — install and update the build tools each runtime needs (shown as ready / not installed / installing / downloading / failed).
- **Runtimes** — install the PHP and Python runtimes directly.
- **Composer** — install Composer (requires PHP first).
- **Frontend builds** — once the packager is ready, the environment can build front-end projects.
- **Cache** — view cache size, clear cache, and reset the environment to recover from a broken state.

## Notes
