# Runtime Management

Downloads and manages the runtime binaries used by server-runtime apps. Open it from [⋮ → Runtime Management](/guide/main-screen/more).

## Runtimes managed

- **PHP runtime**
- **WordPress core**
- **Node.js runtime**
- **Python runtime**
- **Go runtime**

## Features

- **Per-runtime status** — ready / missing, with download progress.
- **Download all** — fetch everything you need in one go.
- **Pause / resume / cancel** — control individual downloads.
- **Clear** — remove a runtime or clear all (with confirmation).
- **Filters** — show all, only missing, or only ready.
- **Mirror** — automatic mirror selection, with a CN mirror option.

## Notes

- Large downloads use an extended-timeout download client.
- Runtimes are downloaded on first use and cached for reuse across apps.
- For toolchains and build dependencies, see [Linux Environment](/guide/more-features/linux-environment).
