# Dual-Pane File Manager

The home screen opens a dual-pane file workspace. Choose a folder for each pane with Android's system picker; access is retained on this device.

## Features

- **Independent folders** — browse and search both locations independently.
- **File operations** — multi-select, copy or move between panes, create folders, rename, delete, and compare files.
- **Text editing** — edit supported text files up to 1 MiB; a private backup is kept when saving.
- **Resizable layout** — panes are side by side on wide screens and stacked on phones; drag the divider to adjust their sizes or swap them.
- **My apps** — return to the app list from the top bar.

## Notes

- Android asks you to grant access to each folder. The selected folder and its access permission are saved locally.
- [⋮ → File Manager](/guide/main-screen/more) remains available for APK/AAB outputs, build logs, and app-generated files.
- Copy and move require both panes to have writable access. Move asks for confirmation and removes originals only after copying succeeds.
