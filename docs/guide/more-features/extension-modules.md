# Manage Plugins

Manage the plugins that run inside your generated apps. Open it from [⋮ → Manage Plugins](/guide/main-screen/more).

## What you can manage

Built-in plugins, custom HCJ packages, userscripts, and MV3 Chrome extensions — all on one unified surface.

## Features

- **List & toggle** — enable or disable installed plugins, pin favorites to the toolbar.
- **Editor** — create or edit a plugin: manifest, JavaScript, CSS, and a `panel.html` UI. See [HCJ Plugins](/extensions/js-module).
- **Market** — browse the community plugin market. See [Publish to the Market](/extensions/publish).
- **Browser extensions** — search the Chrome Web Store live and install MV3 extensions. See [Chrome MV3](/extensions/chrome-mv3).
- **Host style** — pick how plugin entries appear (toolbar button / floating handle / menu) and how panels are hosted (bottom sheet / floating window / fullscreen).
- **Import / export** — `.hcj` packages, `.user.js` userscripts, `.zip`/`.crx` extensions.
- **AI developer** — jump to [Agent](/guide/more-features/agent) to generate a plugin.
