# Usage Stats

Per-app analytics and URL health monitoring. Open it from [⋮ → Usage Stats](/guide/main-screen/more).

## Usage statistics

- **Launches** — total and per-app launch counts.
- **Active apps** — how many apps have been used.
- **Average session** and **last session** — session duration metrics.
- **Rankings** — apps ranked by launches or recent use.
- **Sort** — by launches or recent.
- **Clear all** — reset statistics (with confirmation).

## URL health

- **Check** — test one app's target URL, or check all.
- **Status** — online / slow / offline / unknown, with response time and last-checked timestamp.
- The same status appears as a [health dot](/guide/main-screen/app-list) on app cards.

## Notes

Statistics are collected locally on-device.
