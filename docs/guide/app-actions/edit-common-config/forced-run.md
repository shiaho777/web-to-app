# Forced Run

Configures forced-run behavior for the generated app.

**Where:** the **Forced run** card in the [Edit Common Config](/guide/app-actions/edit-common-config/) editor (backed by `ForcedRunConfig`).

## Options

Configure how the app keeps itself running (forced-run policy), exported as part of the app's runtime configuration.

## Notes

- Forced run is a technical demonstration feature — use only with informed user consent.
- It interacts with the background-run and auto-start options; see [Auto-start](/guide/app-actions/edit-common-config/auto-start) and [APK Export Config](/guide/app-actions/edit-common-config/apk-export).
