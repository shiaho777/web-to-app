# Icon & App

Disguises the generated app's icon and name on the device — multiple launcher icons, "icon storm" modes, and randomized names.

**Where:** the **Icon & App** card in the [Edit Common Config](/guide/app-actions/edit-common-config/) editor (backed by `DisguiseConfig`).

## Options

- **Enable** — turn icon/app disguise on.
- **Multiple launcher icons** — create several launcher entries (`multiLauncherIcons`); an impact-level indicator shows how aggressive the setting is.
- **Icon storm mode** (`iconStormMode`) — e.g. `NORMAL` and stronger modes.
- **Randomize names** — randomize the generated app's name (`randomizeNames`).
- **Custom name prefix** — a prefix for generated names (`customNamePrefix`).

## Notes

- This affects the exported app's launcher presence; the base icon and name are set in [App Icon](/guide/app-actions/edit-common-config/app-icon) and [App Name](/guide/app-actions/edit-common-config/app-name).
- Icon Storm is a demonstration feature — use only with informed user consent.
