# BlackTech

A set of advanced device-action hooks for the generated app.

**Where:** the **BlackTech** card in the [Edit Common Config](/guide/app-actions/edit-common-config/) editor (backed by `DeviceActionsConfig`).

## Options

Configure the device actions the generated app can perform (the "BlackTech" capability set), exported as part of the app's runtime configuration.

## Notes

- BlackTech is a technical demonstration feature — use only with informed user consent and appropriate rights.
