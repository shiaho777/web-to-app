# Edit Common Config

Opens the **shared** configuration every app has — appearance, networking, privacy, and export. Tap ⋮ on an app card, then **Edit Common Config**.

## What it edits

The common editor is a scroll of capability cards:

- **Basic info** — name, icon.
- **Appearance** — toolbar, fullscreen, orientation, splash screen, background music. See [Appearance](/guide/config/appearance).
- **Networking** — DNS, proxies, TLS fingerprint, ECH, CORS. See [Network](/guide/config/network).
- **Privacy** — activation, ad blocking, fingerprint disguise, encryption. See [Privacy](/guide/config/privacy).
- **Extensions** — attached modules, userscripts, MV3 extensions. See [Extensions](/extensions/).
- **Behavior** — announcements, translation, auto-start.
- **Export & permissions** — package name, version, signing, runtime permissions. See [Build APK](/guide/app-actions/build-apk).

A full card-by-card index is in [App Configuration](/guide/config/).

## Notes

- For **Web** apps this is simply called **Edit** (Web has one combined editor).
- For the type-specific source/runtime settings, use [Edit Core Config](/guide/app-actions/edit-core-config).
