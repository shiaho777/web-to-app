# Install APK

Open the APK installation screen from the home screen's ⋮ menu to inspect and install an APK selected from device storage.

## Select and inspect

Choose an APK through Android's system file picker. WebToApp checks that the selected file is a valid package and displays the package name, app name, version, and file size before continuing.

## Install

Tap **Install** to open Android's package installer. If Android asks for permission to install unknown apps, grant it in system settings and return to WebToApp. The system installer requires the user to confirm the installation; WebToApp does not silently install packages.

Installation availability and outcomes depend on Android's policy, the selected package, and the device. Read any error shown by the system installer for the reason an installation could not proceed.
